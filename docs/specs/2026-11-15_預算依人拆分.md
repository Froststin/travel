# 預算的每日花費依旅伴拆分

- 日期：2026-11-15
- 來源：使用者需求「預算的每日花費依 USER 拆分，如購物清單有一筆機票 ×2 27000，預算那邊會變成 A 13500、B 13500」，經反問釐清

## 1. 要做什麼

只在兩人以上的共用旅程出現；一個人的旅程畫面維持原樣。

- 預算頁新增「👥 每人花費」區塊（使用者補充：每人花費分開，個別總計與全部總計都要列出）：
  - 每位旅伴一列：名字、整趟負擔的總計、佔全部的比例（長條）
  - 最後一列「全部總計」
- 「每日花費」表格：「花費」改叫「全部」，後面每位旅伴各多一欄，顯示那天由他負擔的金額；最後加一列「總計」（每人總計＋全部總計）
- 預估花費、分類花費、每日花費的合計改成整趟旅程的總花費：旅伴的購物清單也算進去（原本只算自己的）
- LINE 傳「預算」：預估花費一樣是整趟的總花費，並多列出「每人花費」（每人總計＋全部總計）

## 2. 規則

- 每筆金額算在誰身上，照「分攤的人」平分，跟分帳一樣：
  - 行程花費（含車資）：有勾分攤的人就由這些人平分，沒勾（大家平分）就由全部成員平分；有沒有填「誰付的」都一樣
  - 購物（單價 × 數量）：勾了誰就由誰平分，跟有沒有填「誰付的」無關（2026-11-15 使用者回報修正：原本沒填誰付的會全算在清單主人身上）；購物的勾選照實際存（全勾也存成每個人），新項目預設只勾自己；舊資料沒設定過的：有填誰付的＝大家平分，沒填＝清單主人自己買的
  - 分帳結算：購物要填了「誰付的」才算錢的往來；分給別人卻沒填誰付的，列入「還有 N 筆沒填誰付的」，卡片上也標「還沒填誰付的」
  - 購物表單全部沒勾＝只有自己；分攤對象都已退出時，編輯畫面退回預設勾選；原本分給已退出旅伴的份額存檔時保留
  - 取捨（審查第 6、8 項）：舊資料「有填誰付的＋沒勾」一編輯就存成當下全部成員，之後加入的旅伴不會分到；還開著 v35 舊網頁存檔時全勾會存成空的（版本 36 會自動更新，影響時間很短）
  - 線上檢視頁帶旅伴「有填誰付的或有分給別人」的購物，他自己買的不帶
- 例：機票 ×2、小計 27000，A、B 兩人分攤 → A 13500、B 13500
- 已退出的旅伴：還有被分到的金額時，另外列一欄「已退出的旅伴」，沒有就不列
- 不指定日期的購物，放在表格的「🛒 購物清單（不指定日期）」那一列，同樣依人拆分
- 金額一律換算成台幣；還沒有匯率時，跟現在一樣先用原數字並顯示提醒
- 每日行程頁上每天的金額不變（那裡只列自己的購物清單）
- 免登入的線上檢視頁只拿得到旅伴「有填誰付的」購物，所以拆分只會包含這些（頁面已經註明是分享者看到的內容）

## 3. 實作位置

- 前端
  - `js/split.js`：新增 `memberShares(t, dates)`，回傳每位成員每天、不指定日期、整趟的負擔金額（純函式）
  - `js/app.js`：`budgetData` 把旅伴的購物算進去；`budgetView` 加「每人花費」區塊，每日表格加每人欄位與總計列
  - `css/style.css`：表格欄位變多時，手機上可以左右捲動
- 後端
  - `gas/Split.gs`：新增 `memberShares_(trip)`（和前端同算法）
  - `gas/Export.gs`：`budgetSummary_` 在共用旅程把旅伴的購物也算進去
  - `gas/Bot.gs`：`cmdBudget_` 多列出「每人負擔」
- 測試（`gas/test/run.cjs`）
  - 機票 ×2 27000、A／B 分攤 → 各 13500
  - 沒填誰付的購物算在清單主人身上；行程沒勾分攤的由全部成員平分
  - 每人合計加起來等於總花費
  - LINE「預算」列出每人花費與全部總計，總花費包含旅伴的購物
