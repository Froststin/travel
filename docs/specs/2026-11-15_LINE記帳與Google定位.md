# LINE 記帳、查不到的地點改用 Google 定位

- 日期：2026-11-15
- 來源：使用者需求
  1. 「在 LINE 上多記帳功能，如 12/4 有買東西，我在 LINE 上打『晚餐 1700 我付』，則在預算內的分帳多一筆：晚餐 待分帳 霜付」
  2. 「地圖上查不到地點的，可直接以地點的名稱，找 Google Map 的位置」
  3. 「匯出的靜態網站，讓我可以勾選」（確認：匯出的檔案裡可以打勾）
  4. 「把日本東京常見的地鐵圖，放到地鐵中」
  5. 「行李目前有依 USER 區分嗎？」→ 確認：改成每人各一份＋共用清單

## 1. 要做什麼

### A. 記帳
- 每趟旅程新增一份「記帳」清單（整趟共用），不放進每日行程
- LINE 直接打「項目 金額 誰付」就記一筆，不用關鍵字（開頭加「記帳」也可以）：
  - `晚餐 1700 我付`、`12/4 晚餐 1700 我付`、`計程車 2300円 小明付`、`門票 3000 我付 我和小明`（最後一段指定分攤的人）
  - 回覆：「🧾 已記帳：12/4 晚餐 NT$1,700｜霜付・3 人平分（每人約 NT$567）・待分帳」
  - LINE 傳「記帳」：列出這趟旅程的帳（待分帳在前）
- 網站預算頁新增「🧾 記帳」區塊：依日期列出每筆（項目、金額、誰付的、分攤、待分帳／已結清），可以新增、修改、刪除、按「結清」
- 記帳金額算進預算（預估花費、分類「🧾 記帳」、每日花費、每人花費）與分帳結算

### B. 查不到的地點改用 Google 定位
- 地圖分頁與想去清單的「整理」：OpenStreetMap 查不到時，自動改請後端用 Google 的地點查詢（Apps Script 內建 Maps 服務，不用金鑰、不用綁付款帳戶）以地點名稱找位置
- 之前已經標成「找不到」的地點，登入後打開地圖分頁會用 Google 再查一次
- 沒登入（後端不能用）時，「找不到位置」清單每一筆旁邊有「在 Google 地圖搜尋」連結

### C. 匯出的靜態網站可以打勾
- 匯出的 HTML 檔裡，購物清單、行李清單的每一項都可以點一下打勾／取消
- 勾選記在打開檔案的那台裝置（瀏覽器的 localStorage），重新打開還在；不會同步回網站
- 一開始的勾選狀態照匯出當下；檔案裡加一小段 JavaScript（原本是完全沒有 JavaScript），瀏覽器擋 JavaScript 時照樣能看、只是不能勾
- 線上檢視連結不變（只能看）

### D. 東京常用地鐵圖
- 目的地（或旅程名稱）有「東京／Tokyo」時，地鐵分頁上方顯示「東京常用地鐵圖」：
  - 內建（可放大檢視）：Wikimedia Commons 的東京地鐵路線圖日文版、英文版（Hisagi／氷鷺，CC BY-SA 3.0，2020-08 版），圖下註明作者、授權與來源連結；圖直接從 upload.wikimedia.org 載入，不存進 repo
  - 官方連結：東京 Metro（英文頁、PDF）、都營地下鐵（頁面、全路線圖 PDF）、JR 東日本首都圈路線圖 PDF
  - 註明「2020 年版，最新站名請看官方圖」
- 官方圖有著作權，網站只放連結；使用者可以自己下載後用「上傳地鐵圖」存進旅程

### E. 行李：每人各一份＋共用清單
- 行李分頁分成「🧳 共用」（大家一起帶的，成員都能改，就是原本的清單）與「🙋 我的」（只有自己能改），旅伴的清單列在下面、只能看
- 現有項目都留在「共用」
- 沒登入（只有自己）時畫面跟原本一樣，只有一份
- LINE「行李」：列出共用＋自己的
- 後端：新工作表 `Packing`（id、tripId、userId、text、done），存檔只換存檔者自己的列（跟購物清單一樣）

## 2. 規則

### 記帳
- 一定要有「…付」才認成記帳，不會跟其他指令搞混；開頭是「修改／刪除／新增／買／買到／不買」等指令的不算
- 誰付的：「我付」＝傳訊息的人；「小明付」＝用名字比對旅程成員（包含即可）；比對不到時回覆成員名單、不記帳
- 一個人的旅程（沒有旅伴）也可以記，只算進預算
- 日期：有寫日期就記在那天（要在某趟旅程期間）；沒寫時，今天在旅程期間就記今天，不然記在目前或即將出發的旅程、不指定日期
- 金額：寫「円／¥／日幣」記成日幣，「NT$／台幣／元」記成台幣，沒寫就是旅程幣別；畫面一律換算台幣
- 分攤：沒指定＝所有成員平分（之後加入的旅伴也算）；指定時照指定的人
- 狀態：新記的是「待分帳」，算進分帳；按「結清」後不列入分帳，預算與每人花費照算（跟購物「已買」一樣）
- 每趟最多 300 筆；項目名稱最多 40 字
- 權限：成員都能新增、修改、刪除（跟行程一樣）

### Google 定位
- 順序：OpenStreetMap → 查不到才用 Google；查到的存在行程或想去清單上，旅伴不用再查
- 後端用 `Maps.newGeocoder()`，以目的地附近的範圍優先（避免同名地點跑到別的國家）；結果快取 6 小時
- 個人帳號每天約 1,000 次的上限；用完或失敗時照舊標成「找不到」

  - 網站存檔保留記帳、權限、LINE 存檔不會清掉記帳
