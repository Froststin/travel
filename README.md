# 旅程手帖（靜態旅遊行程規劃網站）

純 HTML／CSS／JavaScript，不需要安裝或建置，資料存在瀏覽器的 localStorage。

## 使用

- 直接用瀏覽器開啟 `index.html`，或在此資料夾執行 `python3 -m http.server 8000` 後開 http://localhost:8000
- 第一次使用可按「載入範例行程」看範例

## 功能

- 多個旅程管理，首頁顯示倒數天數／旅行中／已結束
- 依出發～回程日期自動產生每日行程；項目含時間區間（開始～結束）、移動時間、類別、地點、花費、備註，依時間自動排序，可改日期移到別天
- 移動方式（步行／電車／公車／計程車／開車／腳踏車／飛機／船）、移動時間與車資：行程之間顯示「🚃 電車 15 分鐘・¥230」，車資可選日幣或台幣，日幣會以臺灣銀行現金賣出匯率（FinMind 每日資料，備援為國際參考匯率，快取 6 小時）即時換算台幣，並換算後計入預算的交通類，導航自動切換對應的 Google 地圖交通方式，上一站結束＋移動時間趕不上下一站時會出現 ⚠️ 警告；新增時自動帶入開始時間
- 行程的花費可以選日幣或台幣（旅程是其他幣別時也可以選旅程幣別），選日幣時表單下方即時顯示換算後的台幣；每個行程也可以放一張照片（登入後存在雲端硬碟的「旅程手帖行程照片」，同旅程的成員都看得到）
- 金額一律以台幣為主：台幣只顯示台幣，外幣顯示「NT$47（¥230）」；預算、每日與分類花費都換算成台幣加總（日幣用臺銀現金賣出，其他幣別用國際參考匯率）
- Google 地圖：地點一鍵開啟地圖、🧭 導航（從目前位置出發），每天還有「🧭 路線」串起當天所有地點；也可以貼上 Google 地圖分享連結
- 預算頁：總預算、預估花費、剩餘／超支、分類花費、每日花費
- 待去清單（「📍 想去」分頁）：先把想去的地方都丟進來，按「整理待去清單」會用 OpenStreetMap 查出每個地點的位置，把距離近（約 3 公里內）的分成一組，方便排在同一天；可以整組或單獨排進某一天（會新增成沒有時間的行程）。定位不一定準，每個地點會顯示查到的是哪裡；按 ✎ 可以改名稱、Google 地圖的地址，或貼上 Google 地圖連結（網址列上的完整連結含座標，會直接用那個位置），地圖、導航與排進行程時都會用這個地址。整個旅程共用
- 購物清單：跟著每日行程走。每樣東西可以指定「哪一天買」或「在哪一站買」，會直接顯示在每日行程的那一站底下，也有獨立分頁依天分組、勾選進度；指定行程的東西，行程改到別天會跟著走，行程刪掉則留在那一天；每樣可填預估金額（旅程幣別），會計入預算的「購物」分類與當天花費。購物清單分頁是卡片式：每樣東西可以放一張照片（點照片看大圖）、寫備註（數量、顏色、注意事項），備註和金額在卡片上直接改；每日行程裡會顯示縮圖與備註
- 行李清單：勾選進度、一鍵加入常用物品
- 匯出 PDF（登入後）：旅程頁的「匯出 PDF」由後端產生 PDF、存到 Google 雲端硬碟並回傳連結，和官方帳號的「匯出」是同一套
- 備份檔：匯出／匯入 JSON（單一旅程或全部備份）
- 匯出靜態網站：旅程頁的「匯出靜態網站」會把整趟旅程（每日行程、預算、購物清單、行李、日誌與照片）做成單一 HTML 檔，樣式內嵌、沒有 JavaScript，不靠這個網站或雲端就能開；產生好之後可以選「下載檔案」「在新分頁開啟」或（手機）「分享／存到檔案」，一種方式被瀏覽器擋掉時可以換另一種；日誌照片會先縮小再放進去。內容是匯出當下的快照
- 畫面精簡：旅程頁只有「分享到 LINE」「編輯」和「⋯」（匯出、備份檔、複製、刪除收在裡面）；每天只有「＋ 新增」和「⋯」（路線、要買、住宿交通、分享、複製這天）；點行程卡片就能編輯，刪除、複製、在這裡要買都在編輯視窗裡；交通、地圖連結、備註、照片收在表單的「更多」
- 分頁列和 Day 跳轉固定在上方；預算頁的每日花費點了跳到那天
- 刪除行程、購物、想去、行李、住宿交通後可以按「復原」（約 6 秒內，雲端照片也會拿回來）；表單改過沒存就關閉時會先問
- 今天模式：旅行期間打開旅程會捲到今天，最上面顯示「下一站、還有幾分鐘」與導航，今天的行程標出「進行中／下一站」，每分鐘更新
- 天氣預報：出發前 16 天內，每天標題下顯示天氣、氣溫與降雨機率（Open-Meteo，免金鑰；位置用那天排進行程的想去地點，否則用目的地）
- 拖曳排序：按住行程左邊的 ⠿ 拖到別的位置或別天；同一天換順序時「時段不動、人換位置」，每個行程的長度不變；拖到別天保留原本的時間
- 複製：編輯視窗的「複製」可以改日期再存；每天的「⋯ → 複製這天的行程到…」；旅程的「⋯ → 複製成新旅程」會依新出發日平移行程
- 住宿與交通：航班、飯店、車票、租車、票券連同確認碼，在「每日行程」最上面一覽；當天會列在那天標題下（住宿從入住到退房每天都列），匯出與 LINE「訂位」也看得到
- 分帳（共用旅程）：每筆花費可以選「誰付的」與分攤的人（沒改就是大家平分），預算頁的「🤝 分帳」算出每人付了多少、應分攤多少，以及最少筆數的轉帳；LINE 輸入「結算」也查得到。購物清單是每個人自己的，不算在內
- 安裝到手機主畫面（右上「⋯」）：像 App 一樣開啟，沒網路也打得開，顯示最後一次同步的資料，修改等連上後自動補傳
- 支援手機版與深色模式
- 分享到 LINE：整趟旅程或單日行程（見下方「LINE 整合」）

## 注意

- 沒有用 LINE 登入時，資料只存在目前這個瀏覽器，清除網站資料或換裝置前請先「匯出全部」；用 LINE 登入後改以雲端為準
- 雲端同步失敗時，修改會先留在這台裝置並自動重試，重新整理後也會補傳；若這期間旅程已在其他地方被更新，以雲端為準
- 旅程最長 60 天；縮短日期時，範圍外的行程項目會在確認後刪除

## LINE 整合

- **分享連結（不需設定）**：旅程頁的「分享到 LINE」分享整趟旅程，每天的「LINE」按鈕只分享那一天；內容是純文字，透過 `https://line.me/R/share` 送出
- **LIFF（需設定）**：在 `js/config.js` 填入 `liffId` 後，從 LINE 內開啟網站時，分享會改用 shareTargetPicker 傳送 Flex Message 行程卡片（每天一張，最多 12 天）；不支援或失敗時自動退回純文字分享

### LIFF 設定步驟

1. 把網站部署到 https 網址（例如 GitHub Pages）
2. LINE Developers Console → 選 Provider → 建立 **LINE Login** channel
3. channel 的「LIFF」分頁 → Add：Size 選 `Full`、Endpoint URL 填步驟 1 的網址、Scopes 勾 `profile`、打開 **shareTargetPicker**
4. 把拿到的 LIFF ID 填進 `js/config.js`，重新部署
5. 用 `https://liff.line.me/<LIFF ID>` 開啟；channel 在 Developing 狀態時只有管理員／測試者能用，要給其他人用需改成 Published

## LINE 官方帳號＋雲端同步（`gas/`）

用 LINE 登入後，網站與 LINE 官方帳號共用同一份資料（Google 試算表；日誌照片存 Google 雲端硬碟）。

- 在官方帳號輸入花費時，寫「400円／¥400」記成日幣、顯示時換算台幣；只寫「$400」就是旅程的幣別
- 官方帳號輸入「訂位」列出住宿與交通（確認碼）；查某一天時也會附上當天的航班與入住／退房；輸入「結算」看分帳
- 待去清單也能在官方帳號操作：「想去 淺草寺、晴空塔」「待去清單」「不去 晴空塔」；分組要到網站按「整理」
- 購物清單的照片：上傳前在瀏覽器縮小成 JPEG（長邊 1000 像素）。登入後存在 Google 雲端硬碟的「旅程手帖購物清單照片」資料夾，上傳的人和同旅程的成員讀得到，讀過的會記在裝置上；換照片或刪掉項目時舊檔會丟到垃圾桶。沒登入時照片縮得更小，跟著旅程存在瀏覽器裡
- 購物清單依登入的 LINE 帳號分開儲存：共用旅程裡每個人各有一份，只能改自己的；旅伴的清單（含照片、備註）看得到但不能改，網站的購物清單分頁與官方帳號的「購物清單」都依使用者分區顯示。預算裡的購物金額與每日行程上的「要買」只算自己的
- 購物清單也能在官方帳號操作：「買 明天 抹茶粉、八橋」「買 面膜 @藥妝店」「購物清單」「明天要買什麼」「買到 抹茶粉」「不買 八橋」；金額可以直接寫在後面（「買 明天 抹茶粉 500円」「買到 抹茶粉 480円」會改成實際金額）；查某一天的行程時會一併列出那天還沒買的東西
- 線上檢視連結：免登入、只能看的網頁，網址是 `<網站網址>?view=<代碼>`：網頁憑代碼跟後端要資料，再用和「匯出靜態網站」同一套版面畫出來，內容會跟著行程更新。（不直接用 Apps Script 產生頁面，因為瀏覽器登入多個 Google 帳號時會打不開。）在網站「匯出靜態網站」的視窗按「取得連結」，或在官方帳號傳「匯出」都會拿到；每個人每個旅程一個連結，可以換新（舊的立刻失效），產生連結的人退出或旅程刪除後也會失效。在 LINE 裡開網站、瀏覽器擋下載和分享時就用這個
- 匯出備份：在官方帳號傳「匯出」（或按快速按鈕「📤 匯出」、旅程卡片的「匯出 PDF」），會回覆 PDF 連結（存在 Google 雲端硬碟，知道連結的人可檢視）、網站連結，以及一份純文字行程。PDF 是匯出當下的快照，網站打不開時也能看；同一個人同一個旅程只保留最新一份，舊連結會失效
- 官方帳號可以：查詢（今天／明天吃什麼／清水寺幾點等口語問法）、新增／修改／刪除行程、建立旅程、寫旅遊日誌、傳照片記錄、查預算與行李、取得網站連結、Google 地圖導航（「導航 清水寺」「今天路線」）
- 旅伴共用：LINE 傳「邀請」或網站按「＋ 邀請旅伴」產生邀請訊息，旅伴在 LINE 傳「加入 邀請碼」即加入；主人移除成員後舊邀請碼會作廢；成員都能查看／編輯行程、共用日誌（標註作者），購物清單則是各自一份（互相看得到、不能改），只有主人能刪除旅程與移除成員
- 網站新增「📔 日誌」分頁；在 LINE 做的修改，切回網頁時自動重新載入；兩邊同時改同一個旅程時，網站會提示並重新載入，不會覆蓋

### 安全性

- 機密（`CHANNEL_ACCESS_TOKEN`）放在 Apps Script 的指令碼屬性，不在程式碼裡
- Apps Script 讀不到 HTTP header，無法驗證 LINE 簽章，改用 Webhook 網址上的隨機金鑰（`WEBHOOK_KEY`）
- 網站 API 以 LINE Login ID token 驗證使用者，每個人只能存取自己的資料；驗證後發一張 30 天的登入憑證（HMAC 簽章，金鑰在指令碼屬性 `SESSION_SECRET`，第一次用到時自動產生），網站之後用它就不必每小時重新登入 LINE；用超過 7 天自動換新；網站「⋯ → 登出」會讓這個帳號所有舊憑證失效（記在 Users 的 `sessionsFrom`）
- 刪掉的行程或購物項目，照片先丟到雲端硬碟的垃圾桶；6 小時內按「復原」存回來時，同一個旅程（行程照片）或同一個人（購物照片）才拿得回來
- 想限制只有自己能用：在指令碼屬性設定 `ALLOWED_USERS`（LINE userId，逗號分隔）
